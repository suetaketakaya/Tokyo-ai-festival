# Claude Code統合ガイド

RemoteClaudeAppは、Claude Codeとの統合機能を提供し、開発効率を大幅に向上させます。

## 🚀 機能概要

### 1. WebSocket接続安定性の向上

**実装内容:**
- 指数バックオフによる自動再接続
- 接続品質の動的監視
- レイテンシベースの接続調整
- 詳細な接続メトリクス

**改善点:**
- 再接続試行回数: 5回 → 10回
- ハートビート間隔: 30秒 → 15秒
- 接続品質レベル: excellent, good, poor, unstable
- メトリクス追跡: 応答時間、再接続数、稼働時間

### 2. Claude Code統合システム

**ClaudeCodeIntegrationService**
- プロジェクトコンテキストの自動収集
- 開発セッション管理
- 学習データの蓄積
- 最適化されたプロンプト生成

**特徴:**
- React Native専用テンプレート
- コマンド実行結果の学習
- エラーパターンの分析
- 生産性メトリクスの追跡

### 3. スマートプロンプト生成

**カテゴリ別テンプレート:**
- 🔧 **機能開発**: React Native機能実装の最適化
- 🐛 **デバッグ**: エラー分析と解決策提案
- ⚡ **最適化**: パフォーマンス改善
- 👀 **レビュー**: コード品質チェック
- 📝 **ドキュメント**: 技術文書作成

## 📱 使用方法

### 1. Claude Code統合パネルの起動

1. DevelopmentScreenのヘッダーで🤖ボタンをタップ
2. 統合パネルが開きます

### 2. 開発セッションの開始

```typescript
// 自動で実行される処理
ClaudeCodeIntegrationService.setProjectContext(projectId, projectName);
const sessionId = ClaudeCodeIntegrationService.startDevelopmentSession();
```

### 3. プロンプト生成の使用

1. **タスク内容を入力**
   ```
   例: "ユーザー認証画面にGoogle Loginボタンを追加したい"
   ```

2. **カテゴリを選択**
   - 機能開発、デバッグ、最適化、レビュー、ドキュメント

3. **プロンプト生成ボタンをタップ**

### 4. 生成されるプロンプト例

```markdown
# React Native機能開発アシスタント

## プロジェクト情報
- プロジェクト: RemoteClaudeApp
- タイプ: react-native
- 言語: ["TypeScript", "JavaScript", "TSX"]
- フレームワーク: React Navigation

## 開発タスク
ユーザー認証画面にGoogle Loginボタンを追加したい

## 現在のセッション情報
- 実行コマンド数: 15
- 成功率: 87%
- 最近のアクティビティ: npm install, expo start, git status

## 共通パターン
npm install: 95% success rate; expo start: 100% success rate

上記の情報を考慮して、最適な実装方法を提案してください。
```
