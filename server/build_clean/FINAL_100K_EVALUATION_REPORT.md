## 🔍 エラー分析

### 主要エラーパターン

#### 1. general との混同 (約30%のエラー)
```
誤分類例:
「CI/CD パイプライン」→ 予測: general, 正解: docker
「テスト自動化」→ 予測: web_app, 正解: general
「モノレポ管理」→ 予測: general, 正解: general (正解だが信頼度低)
```

**原因**:
- `general` カテゴリの定義が「その他」として曖昧
- 開発ツール全般が general に含まれるが、明確な特徴がない

#### 2. machine_learning ↔ data_analysis 混同 (約15%のエラー)
```
誤分類例:
「Pandas大規模データ処理」→ 予測: machine_learning, 正解: data_analysis
「TensorFlowデータ前処理」→ 予測: data_analysis, 正解: machine_learning
```

**原因**:
- 両カテゴリが技術的に重複（データ処理、パイプライン等）
- 製品名だけでは判別困難なケース

#### 3. docker ↔ network 混同 (約10%のエラー)
```
誤分類例:
「Kubernetesネットワーク設定」→ 予測: network, 正解: docker
「nginxコンテナ化」→ 予測: docker, 正解: network
```

**原因**:
- インフラ関連の境界が曖昧
- 両カテゴリが共存するユースケース多数

## 📞 補足情報

### モデル利用方法

```python
import joblib
import numpy as np

# モデル読み込み
model_dir = "/tmp/remoteclaude_models_high_accuracy"
classifier = joblib.load(f"{model_dir}/classifier.pkl")
vectorizer = joblib.load(f"{model_dir}/vectorizer.pkl")
feature_extractor = joblib.load(f"{model_dir}/feature_extractor.pkl")

# 予測
command = "プレビューボタンを生成して表示確認"
X_tfidf = vectorizer.transform([command])
X_eng = feature_extractor.extract_features(command).reshape(1, -1)
X_combined = np.hstack([X_tfidf.toarray(), X_eng])

# 推論
y_proba = classifier.predict(X_combined)
predicted_idx = np.argmax(y_proba)
confidence = np.max(y_proba)

print(f"Category: {categories[predicted_idx]}")
print(f"Confidence: {confidence:.2f}")
```
